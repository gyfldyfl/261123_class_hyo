# Mellow Bean 카페 웹사이트 가이드

이 문서는 2026-11-25 회의에서 정한 내용이다. 사이트를 만들거나 고칠 때는 아래 규칙을 그대로 따르고, 여기 없는 결정이 필요하면 임의로 정하지 말고 사용자에게 먼저 물어본다.
사용자는 웹페이지를 처음 만드는 사람이므로, 코드에 **한국어 주석**을 달아 각 부분이 무엇인지 알 수 있게 한다.

## 1. 컨셉 한 줄 요약

> **하얀 여백 위에 하늘색 한 방울.**
> 깔끔하고 미니멀한 화면에 둥근 글씨로 친근함을 더한, 2030을 위한 모바일 중심 카페 사이트.

| 항목 | 결정 |
|---|---|
| 분위기 | 깔끔하고 미니멀 (여백 많이, 사진이 주인공) |
| 메인 컬러 | 화이트 + 스카이블루 (스카이블루는 **포인트로만**) |
| 주요 방문자 | 2030 SNS 세대 → **모바일 화면 최우선** |
| 구조 | **한 페이지 스크롤형** (홈 배너 → 소개 → 메뉴 → 갤러리 → 오시는 길). 처음엔 여러 페이지형으로 정했으나 2026-11-25에 한 페이지로 변경. 아래 8번의 "페이지"는 한 페이지 안의 섹션으로 읽는다 |
| 폰트 | 둥글둥글 귀여운 느낌 |
| 메인 배너 | 큰 사진 한 장 + 문구 |
| 움직임 | 거의 없이 (색 변화 정도만) |
| 로고 | 글자 로고 |
| 모서리 | 각지게 (border-radius: 0) |
| 콘텐츠 | 가상 내용 (연습용) |

> 디자인 포인트: **둥근 폰트 + 각진 모서리**의 조합이다. 글씨는 부드럽고 틀은 반듯해서, 귀엽지만 유치하지 않은 인상을 준다. 모서리를 둥글게 바꾸지 말 것.

## 2. 색상 (Color)

CSS 변수로 `:root`에 정의하고, 코드에서는 항상 변수 이름으로만 쓴다. 색상 코드를 직접 쓰지 않는다.

```css
:root {
  --color-bg: #FFFFFF;          /* 기본 배경: 흰색 */
  --color-bg-soft: #F7F9FB;     /* 푸터 등 아주 살짝 구분이 필요한 곳 */
  --color-text: #1F2933;        /* 본문 글자: 진한 먹색 (순수 검정 X) */
  --color-text-sub: #6B7680;    /* 설명, 가격 옆 보조 글자 */
  --color-line: #E5E9ED;        /* 구분선, 테두리 */
  --color-sky: #8FD0F5;         /* 스카이블루: 장식용 (밑줄, 작은 점, 구분 바) */
  --color-sky-strong: #1A78B8;  /* 진한 하늘색: 버튼 배경, 링크, 강조 글자 */
}
```

**사용 규칙**
- 화면의 90% 이상은 흰색과 먹색이다. 스카이블루는 아래 경우에만 쓴다.
  - 버튼 배경, 링크/메뉴 hover 색 → `--color-sky-strong`
  - 제목 아래 짧은 밑줄, 현재 페이지 표시, 가격 강조 → `--color-sky` 또는 `--color-sky-strong`
- 연한 `--color-sky`는 흰 배경 위 글자색으로 쓰지 않는다. 너무 흐려서 읽기 어렵다. 글자에는 `--color-sky-strong`을 쓴다.
- 배경 전체를 하늘색으로 칠하지 않는다.
- 그림자(box-shadow)와 그라데이션은 쓰지 않는다. 구분이 필요하면 1px `--color-line` 테두리를 쓴다.

## 3. 글씨체 (Typography)

Google Fonts에서 불러온다.

| 용도 | 폰트 | 이유 |
|---|---|---|
| 로고, 제목 | **Jua** (주아체) | 둥글고 귀여운 느낌. 굵기가 하나뿐이라 제목 전용 |
| 본문, 메뉴 설명, 버튼 | **Gowun Dodum** (고운돋움) | 둥근 느낌이면서 작은 글자도 잘 읽힘 |

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Gowun+Dodum&family=Jua&display=swap" rel="stylesheet">
```

```css
:root {
  --font-title: 'Jua', sans-serif;
  --font-body: 'Gowun Dodum', sans-serif;
}
```

**글자 크기 (모바일 기준 → 데스크톱)**

| 요소 | 모바일 | 데스크톱(1024px~) |
|---|---|---|
| 메인 배너 제목 | 40px | 64px |
| 페이지 제목 (h1) | 28px | 40px |
| 섹션 제목 (h2) | 22px | 28px |
| 본문 | 16px | 17px |
| 보조 글자 (설명, 캡션) | 14px | 14px |

- 줄 간격(line-height): 본문 1.7, 제목 1.3
- 영문 로고 "Mellow Bean"은 자간을 살짝 넓힌다 (`letter-spacing: 0.02em`).
- 본문 글자는 너무 진하게(bold) 쓰지 않는다. 강조는 색(`--color-sky-strong`)으로 한다.

## 4. 레이아웃과 간격

- **모바일 퍼스트**: 기본 CSS는 휴대폰 화면 기준으로 작성하고, 큰 화면은 `@media (min-width: ...)`로 추가한다.
  - 태블릿: `min-width: 768px`
  - 데스크톱: `min-width: 1024px`
- 콘텐츠 최대 너비: `1080px`, 가운데 정렬
- 화면 좌우 여백: 모바일 `20px`, 데스크톱 `40px`
- 섹션 사이 간격은 넉넉하게 준다. 모바일 `64px`, 데스크톱 `120px`. 미니멀한 느낌은 여백에서 나온다.
- 간격 값은 8의 배수로 맞춘다 (8, 16, 24, 32, 48, 64, 120).
- 가로 스크롤이 생기면 안 된다.
- 태블릿(768px~)은 좌우 여백 `32px`, 섹션 간격 `88px`이다.
- 제목 글자 크기는 `clamp()`로 화면 너비에 따라 자연스럽게 바꾼다. 메인 배너 제목은 320px 폰에서도 한 줄을 유지해야 한다.
- 한글이 단어 중간에서 끊기지 않게 `word-break: keep-all`을 쓴다. 문단 안에 `<br>`로 줄을 강제로 나누지 않는다.
- 이미지를 flex 가로 배치에 넣을 때는 `min-width: 0`을 줘서 옆의 글을 밀어내지 않게 한다.
- 확인할 너비: 320px(작은 폰), 375px(일반 폰), 768px(태블릿), 1280px(데스크톱)

**모서리와 테두리**
- 모든 요소 `border-radius: 0` (사진, 버튼, 카드, 입력창 전부)
- 카드에는 그림자 없이, 필요할 때만 `1px solid var(--color-line)`

## 5. 공통 요소

### 헤더 (모든 페이지 동일)
- 왼쪽: 글자 로고 "Mellow Bean" (Jua, `--color-text`)를 누르면 홈으로 이동
- 오른쪽: 메뉴 링크 `Menu` `Gallery` `Location`
- 현재 페이지 링크 아래에 2px `--color-sky` 밑줄을 표시한다.
- 모바일(768px 미만): 링크 3개를 숨기고 ☰ 버튼을 보여 준다. 누르면 메뉴가 펼쳐진다. 이 동작에만 JavaScript를 쓴다.
- 배경 흰색, 아래에 1px `--color-line` 구분선. 스크롤해도 위에 고정(`position: sticky`)

### 푸터 (모든 페이지 동일)
- 배경 `--color-bg-soft`
- 로고, 주소, 영업시간, 전화, 인스타그램 아이디, © 2026 Mellow Bean

### 버튼
- 기본: 배경 `--color-sky-strong`, 글자 흰색, 각진 모서리, 위아래 14px / 좌우 28px
- 보조: 흰 배경, 1px `--color-text` 테두리, 글자 `--color-text`
- 마우스를 올리면 색만 살짝 변한다 (아래 6번 참고).

## 6. 움직임 (Animation)

**거의 없이**가 원칙이다.
- 허용: 링크·버튼 hover 시 색 변화만. `transition: color 0.2s, background-color 0.2s;`
- 금지: 스크롤 등장 효과, 사진 확대(zoom), 슬라이드, 자동 재생, 패럴랙스, 깜빡임
- 모바일 메뉴 열기/닫기는 효과 없이 바로 보이거나 숨긴다.

## 7. 이미지

모든 사진은 `images/` 폴더에 있다. 원본은 `images/originals/`에 있으며 **사이트에서는 원본을 쓰지 않는다.**

| 파일 | 내용 | 사용 위치 |
|---|---|---|
| `cafe-interior.jpg` | 로스팅 공간과 넓은 홀 | 홈 메인 배너, 갤러리 |
| `latte-cookie-set.jpg` | 라떼아트 머그와 쿠키, 꽃 | 홈 소개, 메뉴, 갤러리 |
| `cafe-latte.jpg` | 유리잔 라떼 | 메뉴, 갤러리 |
| `hand-drip-coffee.jpg` | 핸드드립 내리는 장면 | 홈 소개, 메뉴, 갤러리 |
| `strawberry-latte.jpg` | 딸기 라떼 | 메뉴, 갤러리 |
| `lemonade.jpg` | 레몬에이드 | 메뉴, 갤러리 |
| `tiramisu.jpg` | 티라미수 | 메뉴, 갤러리 |

**규칙**
- 모든 `<img>`에 한국어 `alt` 설명을 쓴다 (예: `alt="라떼아트가 그려진 유리잔 카페라떼"`).
- 모든 `<img>`에 `width`와 `height`를 적는다. 로딩 중에 화면이 덜컹거리지 않게 하기 위해서다.
- 메인 배너를 뺀 사진에는 `loading="lazy"`를 쓴다.
- 사진 비율은 `aspect-ratio`와 `object-fit: cover`로 통일한다.
  - 메뉴 카드: `4 / 5` (세로가 약간 긴 비율)
  - 갤러리: `1 / 1` (인스타 피드 같은 정사각형)
- 사진에 필터나 색 보정을 넣지 않는다.

## 8. 페이지별 구성

파일 구조:

```
index.html        한 페이지 전체 (섹션 id: #menu, #gallery, #location)
css/style.css     모든 스타일 (파일 하나)
js/script.js      모바일 메뉴 토글만
images/           웹용 사진
```

헤더 메뉴 링크는 `#menu`, `#gallery`, `#location` 같은 섹션 앵커로 연결한다. 부드러운 스크롤 효과는 넣지 않는다 (움직임 최소 원칙).

### 8-1. 홈 (`index.html`)
1. **메인 배너**: `cafe-interior.jpg`를 화면 가득 채운다. 모바일 높이 `80vh`, 데스크톱 `90vh`.
   - 사진 위에 반투명 어두운 막(`rgba(0,0,0,0.3)`)을 깔아 글자가 잘 보이게 한다.
   - 가운데에 흰 글씨: `Mellow Bean` (Jua) / `하얀 컵에 담은 느긋한 하루` / [메뉴 보기] 버튼
2. **소개**: 짧은 글 2~3줄과 사진 1장 (`hand-drip-coffee.jpg`). 모바일에서는 세로로 쌓고 데스크톱에서는 좌우로 배치한다.
3. **추천 메뉴 3개**: 카페라떼, 딸기라떼, 티라미수 카드 + [전체 메뉴 보기] 링크
4. **방문 안내 한 줄**: 영업시간과 [오시는 길] 링크

### 8-2. 메뉴 (`menu.html`)
- 페이지 제목 `Menu`와 그 아래 짧은 하늘색 밑줄
- 카테고리별로 나눈다: **Coffee / Non-Coffee / Dessert**
- 사진 있는 메뉴는 카드(사진 + 이름 + 한 줄 설명 + 가격)로 보여 준다. 모바일 2열, 데스크톱 3열.
- 사진 없는 메뉴는 카드 아래에 텍스트 목록(이름 ······ 가격)으로 넣는다.
- 가격은 `--color-sky-strong`

### 8-3. 갤러리 (`gallery.html`)
- 페이지 제목 `Gallery`와 짧은 소개 한 줄 (`#mellowbean 의 순간들`)
- 사진 7장을 정사각형 격자로 놓는다. 모바일 2열, 태블릿 이상 4열, 사진 사이 간격 4px (인스타 피드 느낌).
- 첫 사진(매장 내부)은 가로 2칸(2:1 비율)으로 써서 7장이 빈칸 없이 채워지게 한다.
- 클릭 확대, 슬라이드는 만들지 않는다 (움직임 최소 원칙).
- 하단에 인스타그램 아이디 링크

### 8-4. 오시는 길 (`location.html`)
- 페이지 제목 `Location`
- 정보 표: 주소 / 영업시간 / 휴무 / 전화 / 인스타그램
- 찾아오는 방법: 지하철과 주차 안내 2~3줄
- 지도: 구글 지도는 쓰지 않는다. 페이지 맨 아래(푸터 바로 위)에 약도 이미지 `images/cafe-map.png`를 둔다. 반월당역 지도에 카페 위치를 빨간 원으로 표시한 이미지이며, 최대 너비 695px에 1px 테두리를 두른다

## 10. 코딩 규칙

- 순수 HTML + CSS만 쓴다. JavaScript는 모바일 메뉴 토글에만 쓴다. 프레임워크와 라이브러리(Bootstrap, jQuery 등)는 쓰지 않는다.
- 모든 페이지에 `<html lang="ko">`, `<meta charset="UTF-8">`, `<meta name="viewport" content="width=device-width, initial-scale=1">`를 넣는다.
- 각 페이지 `<title>`: `Mellow Bean | 메뉴`처럼 쓴다. 홈은 `Mellow Bean`만 쓴다.
- 의미에 맞는 태그를 쓴다: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
- CSS 클래스 이름은 영문 소문자와 하이픈으로 짓는다 (예: `.menu-card`, `.site-header`).
- `style.css`는 다음 순서로 작성하고, 구역마다 한국어 주석 제목을 단다.
  1. 변수(:root) → 2. 기본 초기화 → 3. 공통(헤더/푸터/버튼) → 4. 홈 → 5. 메뉴 → 6. 갤러리 → 7. 오시는 길 → 8. 반응형(@media)
- 헤더와 푸터는 4개 페이지에 똑같이 복사한다. 하나를 고치면 나머지도 함께 고친다.
